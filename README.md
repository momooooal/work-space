# 千禧的辦公桌

以繁體中文固定模板與瀏覽器檔案工具，完成日常辦公工作。純靜態網頁，不使用 AI API、不需要金鑰，也不會把工作資料傳到 ChatGPT。

## 使用

將這個資料夾放在 GitHub repository 根目錄，於 Settings → Pages 選 Deploy from a branch、main、/(root)。公開版不包含私人公文；首次使用請在網站左下「資料與備份」匯入自己的 ZIP 資料包。

## 功能

- 公文舊案：相同檔名只差末尾括號數字時歸入同案；原簽原函分件保留，14種可填定型稿，可編輯並匯出 Word。
- Excel：讀取所有工作表、分類計數／加總、明確年齡分組、地址拆欄、去重，附實際欄位操作步驟及 CSV／XLSX。
- 社群與回覆：依填入的事實組成固定句型；可直接修改、複製與匯出。
- 文件：列出全部檔案與工作表，匯出資料值、Word、PDF、各表 CSV ZIP；可按順序合併原 PDF。
- 圖卡：文字公告 PNG；在原圖指定矩形覆蓋底色與文字，矩形外保留原圖。
- 查核紀錄：保存使用者提供的來源、日期、原文與核對結果。
- 排錯：以常見錯誤關鍵字列檢查順序，搜尋上傳手冊原文與頁碼。
- 資訊網頁：產生可搜尋及分類的固定版型 HTML，可預覽與下載。

## 資料保存與限制

公文 ZIP 保存於 IndexedDB；工作草稿與偏好保存於 localStorage。沒有帳號同步，更換裝置、網址、無痕模式或清除網站資料後需重新匯入。請定期下載備份。工作附件不隨草稿保存。

不提供自由式 AI 推理、OCR、生成式修圖或自動網路查證。XLSX 讀取已存的值，不執行巨集、不重算公式；匯出資料值不保留原本版面。單檔20MB，一次最多60個工作附件；PDF最多讀300頁文字，原檔合併保留全部頁面。新公文先列待分類，不自動判定核定結果。

PDF文字／表格匯出以影像排版，文字不可搜尋；需要可編輯文字請選Word。PDF表格每5欄分組並重複表頭，全部資料列均保留；超過400頁會停止而不交付不完整檔案。含可填表單的PDF不合併，以免遺失表單。

供自行核對與編輯草稿，不自動發文或傳送回覆。歷史補助條件不代表目前法規或本次審查結果。

## 相依套件

JSZip、PDF.js、pdf-lib 隨站點提供，授權文字在 vendor/。不載入第三方 CDN、不含分析追蹤。網路讀取限同源靜態資產與使用者主動備份原檔；沒有付費服務或 API 設定。
